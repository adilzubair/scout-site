# Scout

Scout is a Windows 11 launcher for finding files, apps, links, and saved
workspaces from one keyboard shortcut.

- [Website](https://adilzubair.github.io/scout-site/)
- [Download the Windows beta](https://github.com/adilzubair/scout-site/releases)

Download the portable ZIP, extract the entire folder, and run `Scout.exe`.
Press **Ctrl+Alt+Space** to open it. The beta is unsigned and has no installer
or automatic updater.

This repository contains the public website and release downloads.
